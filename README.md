**HairCut** is a sleek, modern, and fully responsive website designed for luxury barber shops, built using core web technologies to ensure high performance and speed.

## ✨ Features
*   **Modern UI/UX Design:** A sophisticated dark-themed interface with striking crimson red accents.
*   **Fully Responsive:** Seamlessly optimized for mobile, tablet, and desktop screens.
*   **Interactive Sliders:** Smooth service and promotion displays powered by **Owl Carousel**.
*   **Comprehensive Sections:** Includes service pricing, professional team profiles, and customer testimonials.

## 🛠️ Tech Stack
*   **HTML5 & CSS3:** For semantic structure and visual styling.
*   **Vanilla JavaScript:** For core logic and interactive elements.
*   **jQuery:** To support external library integrations.
*   **Owl Carousel 2:** For responsive and touch-enabled sliders.
*   **Font Awesome:** For professional vector icons.

## 🚀 How to Run
1. Clone the repository.
2. Open the `index.html` file in your preferred web browser.
